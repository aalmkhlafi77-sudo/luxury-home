# Luxury Home — إدارة العقارات

منصة لإدارة المباني والشقق والحجوزات والإيجارات والتحصيل، مع واجهة React وخادم Express وقاعدة بيانات عبر Prisma/PostgreSQL وفق ملفات المشروع.

## التشغيل والتطوير

`npm run dev` للتطوير و`npm run build` للبناء. تتطلب وظائف الخادم وقاعدة البيانات إعداد البيئة.

## ملاحظات

يوثق هذا الملف البنية الموجودة، ولا يثبت اكتمال جميع الوظائف أو نجاح النشر. لا ترفع أسرار البيئة أو بيانات الإنتاج إلى GitHub.
