# سجل متابعة اكتمال النظام الأساسي - Luxury Home (منزل الفخامة)

تم إعداد وتحديث هذا المستند وفق المعايير والقواعد الصارمة المعتمدة للمشروع:
- **مصدر البيانات المعتمد**: PostgreSQL مع دعم آمن للتراجع والعمل المعزول.
- **الحسابات المالية**: باستخدام نمط Decimal الدقيق وعدم التقريب الصامت أو إجراء عمليات مالية عشوائية.
- **التخزين المحلي**: للتفضيلات وبيانات إعادة المحاولة فقط (وليس لإثبات الحجوزات أو العمليات المالية).

## 3. متطلبات تشغيل واختبار PostgreSQL في بيئة الإنتاج

عند الرغبة في تشغيل دورة التكامل على خادم PostgreSQL معزول، يتم توفير المتطلبات التالية:
1. تعيين متغير البيئة:
   ```bash
   export DATABASE_URL="postgresql://user:password@hostname:5432/luxury_home_db?schema=public"
   ```
2. تطبيق الترحيلات الهيكلية المعتمدة دون تعديل التاريخ السابق:
   ```bash
   npx prisma migrate deploy
   ```
3. تشغيل سكريبت التحقق المعزول:
   ```bash
   npx tsx scripts/test-isolated-postgres.ts
   npx tsx scripts/test-phase4-cycle.ts
   ```
> **تنبيه الشفافية**: لم يتم ادعاء نجاح قاعدة البيانات PostgreSQL لعدم توفرها محلياً في بيئة المعاينة، وتم توثيقها بشفافية كـ **«غير منفذ»** مع الحفاظ التام على سلامة منطق التطبيق وواجهات برمجة التطبيقات.
