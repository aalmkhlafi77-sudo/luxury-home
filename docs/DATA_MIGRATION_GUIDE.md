# 🚚 دليل نقل البيانات والوسائط وترحيل قاعدة البيانات (Data Migration Guide)

توضح هذه الوثيقة إجراءات ترحيل البيانات الحالية، ونقل الوسائط والمرفقات إلى الاستضافة الجديدة، وتهيئة قاعدة بيانات PostgreSQL.

---

## 🗄️ أولاً: ترحيلات قاعدة البيانات (Prisma Migrations)

عند تشغيل النظام لأول مرة على بيئة إنتاجية جديدة مع PostgreSQL:

1. **إنشاء جداول قاعدة البيانات بأسلوب سلس:**
```bash
npx prisma db push
```

2. **أو إنشاء ملف ترحيل رسمي وتطبيقه:**
```bash
npx prisma migrate dev --name init_production_schema
```

3. **توليد عميل Prisma Client:**
```bash
npx prisma generate
```

---

## 📤 ثانياً: تصدير واستيراد البيانات التشغيلية (Data Seeding & Migration)

1. **تصدير بيانات التشغيل من النظام الحالي:**
   البيانات محفوظة بصيغة JSON مقيسة داخل الخادم ويمكن تصديرها بنقرة واحدة أو أخذ نسخة من ملف `server-db.json`.

2. **تغذية قاعدة البيانات الميدانية المبدئية (Initial Seed):**
   عند تشغيل النظام لأول مرة دون بيانات، يقوم الخادم تلقائياً بتهيئة البيانات الأساسية من `src/data/initialData.ts` وتشمل:
   - المباني والوحدات وتقسيم الفراغات والتجهيزات.
   - فئات المصاريف الـ 13 ومراكز التكلفة وحصص التوزيع.
   - إعدادات الشروط والأحكام ومصطلحات العقود.

---

## 🖼️ ثالثاً: نقل وسائط الصور والمستندات (Media & Uploads Sync)

1. جميع صور المباني والوحدات ومرفقات العقود والوصلات محفوظة في المجلد:
   `/app/uploads` (أو `./uploads` محلياً).

2. **طريقة نقل الوسائط إلى الخادم الجديد عبر rsync:**
```bash
rsync -avz -e ssh ./uploads/ user@your-server-ip:/var/lib/docker/volumes/ivoire_platform_app_uploads/_data/
```

3. **التحقق بعد النقل:**
   قم بفتح صفحة المبنى والوحدات للتأكد من ظهور الصور وعمل روابط الاستعراض بنجاح.
