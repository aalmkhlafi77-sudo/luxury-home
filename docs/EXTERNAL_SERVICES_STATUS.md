# 🔌 حالة الخدمات الخارجية والتكاملات المحتملة (External Services Integration Status)
**التاريخ:** 2026-09-30  
**النظام:** منصة إدارة العقارات والوحدات الفندقية والمالية (Ivoire Platform)

توضح هذه الوثيقة بوضوح حالة كل خدمة خارجية، وهل هي مفعلة بحساب إنتاجي أم تعمل بنمط بديل آمن (Mock/Fallback Pattern) يضمن عدم توقف أو انهيار أي جزء من النظام عند عدم ربط مفاتيح مزود الخدمة.

---

## 📋 جدول حالة الخدمات الخارجية

| الخدمة الخارجية | المزود المعتمد | حالة الربط الحالية | النمط البديل عند عدم تزويد المفتاح (Fallback Behavior) | المتطلبات للربط الإنتاجي الفعلي |
| :--- | :--- | :--- | :--- | :--- |
| **بوابة الدفع الإلكتروني (Online Payments)** | Mada / Moyasar / Tap | مهيأة ومعزولة بانتظار مفتاح الـ API | تسجيل الدفع النقدي والتحويل البنكي والتأكيد الدفتري دون ادعاء نجاح عملية دفع إلكتروني وهمية | تزويد `PAYMENT_API_KEY` و `PAYMENT_SECRET_KEY` في `.env` |
| **الأقفال الذكية (Smart Locks API)** | Tuya / TTLock API | مهيأة للربط التلقائي عند الحجز | إصدار وتوليد رموز فتح الجلسات مع تنبيه الإدارة للمتابعة المباشرة عند غياب المفاتيح | تزويد `SMART_LOCK_API_KEY` ورقم البوابة |
| **التحقق الحكومي من الهوية (ID Verification)** | Absher / Elm Yakeen API | مهيأة ومعزولة | رفع صور الهوية والإقامة وتوثيقها يدوياً بواسطة موظف الاستقبال مع إظهار حالة "بانتظار التوثيق الميداني" | الحصول على تصريح يقين الرسمي وتزويد `YAKEEN_APP_ID` |
| **الرسائل النصية والواتساب (SMS / WhatsApp)** | Taqnyat / Twilio API | مهيأة وربط الإشعارات جاهز | تسجيل الإشعارات والتنبيهات في سجل النظام ومركز الإشعارات الداخلي للمستخدم دون تعطيل العملية | تزويد `SMS_API_KEY` واسم المرسل المعتمد |

---

## 🛡️ ضمانة الاستقرار التشغيلي (Operational Guarantee)

- جميع الخدمات غير المربوطة **لا تمنع أو تعطل تشغيل باقي أجزاء النظام إطلاقاً**.
- تظهر حالة كل خدمة بوضوح في لوحة الإدارة وفي الاستجابة المباشرة للمسار: `/api/external-services/status`.
- لن يعرض النظام نجاح عملية دفع إلكتروني أو توثيق رسمي ما لم يتم التأكيد الفعلي من مزود الخدمة المعين.
